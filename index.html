Codivizer

Understand the code. See the system.

Codivizer is an interactive codebase explorer designed to help developers understand unfamiliar and complex repositories. Instead of navigating file by file, explore architecture, dependencies, symbols and execution traces through an interactive visual map.

$ npm install -g codivizer
type codivizer in your repository terminal to launch the app
requires Node.js 20+ · no config needed
